# Соответствие NikaS UI v1.9 / Navigation Contract v1.1

Версия интеграции и UI: `0.1.0`.

| Требование | Статус | Реализация |
| --- | --- | --- |
| Постоянные Header, viewport и Bottom Tab Bar | PASS | Оболочка монтируется один раз; проверки запрещают повторное присваивание `shadowRoot.innerHTML`. |
| Стабильное обновление телеметрии | PASS | `set hass()` объединяет обновления в animation frame и меняет только текст/классы. |
| Кэш посещённых вкладок | PASS | Каждая вкладка создаётся один раз и остаётся в `Map`. |
| Масштаб рабочей области | PASS | Gesture-only 75–200%; при 100% работает нативная прокрутка. |
| Безопасный Header return | PASS | Приоритет `return_to`, `from`, одноразовая hand-off запись, сохранённый маршрут, referrer, configured fallback. |
| Явная недоступность данных | PASS | `unknown`, `unavailable`, отсутствие и нечисловые значения отображаются как «Нет данных». |
| Только чтение | PASS | Нет команд оборудованию; разрешён только refresh данных. |
| Автономный production bundle | PASS | Один детерминированный JS без runtime-импортов. |
| Жизненный цикл Recorder | PASS | Кэш на период, максимум два запроса, 60-секундный тайм-аут, конечные empty/error состояния. |
| Явные пороги на форме | PASS | Компактный блок расположен сразу под карточками давления; питьевая норма 2,4–3,1 бар. |
| Проверка на целевом Home Assistant | PENDING | Требуется установка опубликованного репозитория и проверка фактической долгосрочной статистики. |
